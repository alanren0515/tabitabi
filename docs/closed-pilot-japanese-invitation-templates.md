# TabiTabi クローズド試験：日本語DM・返信・4回テスト課題

この文書は、面識のある日本在住ユーザーへ個別に送るための文面です。公開投稿への転載は想定していません。

## 使い方

- `[お名前]`、`[送信者名]`、`[期限]`だけ置き換えてください。
- 招待ページは [TabiTabi クローズド試験の案内](https://tabitabi-jp.fly.dev/pilot) を使ってください。
- アクセスコードはこの文書、公開投稿、URL、画像、グループチャットには書かず、参加条件を確認した相手に個別送信してください。
- 参加者には、ページ内の「プライバシーとデータ」「利用条件」も確認してもらってください。

## 1. 最初の個別DM

### 自然な友人向け

```text
[お名前]さん、こんにちは！少しお願いがあって連絡しました。

いま、SNSで見つけた飲食店を「実際に行ける情報」まで整理する TabiTabi という試作サービスを、少人数でクローズド試験しています。

普段 Instagram や TikTok などでお店を探すことがあれば、15〜20分ほど、いつものスマホで試してもらえないでしょうか？

お願いしたいのは、実際に気になっている別々の飲食店を4件、スクリーンショット・店名・公開リンクなどから確認することです。予約の確定、支払い、電話は必要ありません。結果について短いフィードバックもお願いします。

参加する場合は、まずこちらの案内とプライバシーの説明を確認してください：
https://tabitabi-jp.fly.dev/pilot

興味があれば「参加したい」と返信してください。対象条件と注意点を確認したあと、テスト用のアクセス情報を個別に案内します。コードは公開・転送しないようお願いします。

もちろん、都合が合わなければ遠慮なく断ってください！
```

## 2. 参加希望を受け取った後の返信

### 条件確認をお願いする返信

```text
ありがとうございます！参加を検討してもらえてうれしいです。

次の条件に当てはまるかだけ確認させてください。

・18歳以上で、現在日本国内に住んでいる
・iPhone または Android の普段使いのスマホで試せる
・最近、Instagram、TikTok などのSNSで飲食店を探したことがある
・公開投稿のスクリーンショット、店名、または公開リンクを使える
・テスト中に予約を確定したり、支払ったり、電話をかけたりする必要はないことを了承できる

問題なければ、案内ページのプライバシーとデータ、利用条件も確認したうえで、「確認しました」と返信してください。
```

### 条件確認後の返信（アクセス情報を別送する場合）

```text
ご確認ありがとうございます。参加条件と注意点を確認できました。

これから、テスト用のアクセス情報をこのDMで別途お送りします。第三者への共有、公開投稿、スクリーンショットでの転載はしないでください。現在のタブを閉じると、アクセス情報はブラウザ上から消去されます。

テストは、別々の飲食店を4件、1件ずつ確認してください。画像を使う場合は、公開投稿だけを使い、DM、通知、非公開投稿、他人の個人情報が写っていないことを確認してください。

予約ページを開いても予約成立ではありません。必要なら入口を確認するだけにして、最終的な店舗・支店・日時・人数・料金・キャンセル条件は、店舗または予約サービスの最終画面で確認してください。

終わったら、4件それぞれについて「役に立ったか」「情報は正確だったか」「困った点」を返信してください。よろしくお願いします！
```

### 参加を見送る場合の返信

```text
確認ありがとうございます。今回は条件が合わなさそうなので、参加のお願いはここまでにします。時間を使って確認してくれてありがとうございました！
```

## 3. 1人4回のテスト課題

共通ルール：4回とも別の飲食店を使う／入力前に投稿や店の情報を確認する／候補の店名・エリア・支店を自分で確認する／不確かな候補は無理に選ばない／予約の送信・支払い・電話はしない。

### 1回目：公開SNSスクリーンショット

```text
自分が実際に気になっている飲食店の、Instagram または TikTok の公開投稿を1件使ってください。

1. DM、通知、非公開投稿、他人の個人情報が写っていない状態にする。
2. スクリーンショットを追加する。
3. 抽出された店名・エリア・支店を確認する。
4. 正しい店舗を選び、結果の出典・判断の限界・次の行動を読む。
5. 結果ページのフィードバックに回答する。
```

### 2回目：記憶している店名・文字だけ

```text
スクリーンショットを使わず、行ってみたい別の店について、店名だけ、または店名と駅名・エリアを入力してください。

1. TabiTabi が見つけた候補を比較する。
2. 同名店や別支店ではないか、住所を確認する。
3. 店舗情報と予約・確認先の違いを読む。
4. 入力が少ない状態でも、どこまで安心して次へ進めたかをフィードバックする。
```

### 3回目：別のSNSの公開リンクまたは本文

```text
1回目とは違うSNSの、別の飲食店に関する公開リンクまたは公開本文を使ってください。

1. リンク先が誰でも見られる公開ページであることを確認する。
2. 必要なら店名・エリアを補足する。
3. 投稿の内容と実在店舗の候補が一致するか確認する。
4. 公式サイト、電話、予約サービスなど、提示された入口を区別して読む。
5. 「投稿の情報と現在の店舗情報に差があったか」をフィードバックする。
```

### 4回目：公式サイト・地図・予約サービスの手掛かり

```text
これまでとは別の飲食店について、店名、公式サイト、Google Maps、食べログ、Hot Pepper など、公開されている手掛かりを1つ使ってください。

1. 店名と住所・支店を確認する。
2. 公式サイトや予約サービスへの入口が、予約リクエスト・順番待ち・店舗ページのどれかを確認する。
3. 空席、予約成立、営業時間などを TabiTabi が断定していないことを確認する。
4. 最終確認に必要な情報が分かったか、足りなかった情報は何かをフィードバックする。
```

## 4. テスト終了後の一言

```text
4件のテスト、ありがとうございました！

最後に、次の3点だけ教えてください。
1. 4件のうち、実際に一番役に立った入力はどれでしたか？
2. いちばん不安だった、または分かりにくかった箇所はどこでしたか？
3. 次にSNSで気になる店を見つけたとき、また使いたいと思いますか？

自由なコメントもあればぜひお願いします。良い点だけでなく、うまくいかなかった点もそのまま教えてください。
```

## 運営者メモ（送信しない）

- 参加者に「役に立った」を選ぶよう誘導しない。行動入口も、本人の本来の目的に合う場合だけ開いてもらう。
- 元画像・元の検索文・正確な来店日・APIキーは運営側で記録しない境界を維持する。フィードバックには個人情報を書かないよう案内する。
- 参加者が予約を確定、支払い、電話、個人情報を含む画像の送信をしようとしたら、その回は中止してよい。
- アクセスコードはこのファイルにも、Git、公開ページ、招待文の共有版にも書かない。
