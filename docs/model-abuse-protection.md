# 模型调用与滥用防护审计

## 结论

截图理解使用服务端固定提示词，用户不能提交任意模型指令；Qwen 是主模型，OpenAI 仅在配置后作为低置信度或无效输出的 fallback。API Key 只存在于服务端。部署后的硬性费用边界由访问码、客户端额度、全局并发、图片限制、结果去重和持久化每日预算共同组成。

浏览器中的共享试点访问码只保存在 `sessionStorage`，不会进入长期偏好或本机数据导出；关闭当前标签页后需要重新输入。

## 已发现并修复

### MAB-01 · 高：fallback 未单独计数

此前一次截图即使先调用 Qwen、再调用 OpenAI，也只扣一个视觉请求预算。现在每个供应商尝试在上游调用前独立扣减：Qwen 最多 60 次/东京日，OpenAI fallback 最多 10 次/东京日。fallback 用尽时保留可人工确认的 Qwen 结果，不继续付费。

### MAB-02 · 中：相同截图可重复计费

此前完全相同的截图会重复调用模型。现在按解码后的图片字节计算 SHA-256，仅在内存中保存哈希键和结构化结果十分钟；不保存原图。相同图片的并发请求会合并成一次上游调用。

### MAB-03 · 中：不同客户端可形成并发尖峰

此前只有每 IP 每分钟限流，多个 IP 仍可同时占用模型。现在全局最多同时接收和解码四个图片请求、运行两个未缓存模型任务；额外请求立即返回 429。每个客户端同时受四次/分钟和二十次/真正滚动 24 小时限制，全局持久化预算仍是最终费用熔断器。

### MAB-04 · 中：图片尺寸和输出上限不够严格

此前请求体限制间接约束文件大小，但没有像素和单边尺寸上限；模型输出环境变量也没有最大值。现在图片超过 8 MB、2,000 万像素或单边 10,000 px 会在供应商调用前拒绝。输出默认 1,200 tokens，代码硬上限 1,800，部署预检拒绝更高配置。

### MAB-05 · 高：凭证泄露或供应商异常缺少秒级止损

新增独立于每日预算的持久化异常熔断：五分钟内 Qwen 10 次、OpenAI 3 次、Google Places 20 次、Hot Pepper 20 次真实上游请求即停止对应供应商；同一供应商两次鉴权/限流错误或五次网络、超时、5xx 错误也会隔离该供应商六小时。模型 JSON/Schema/低置信度等质量问题不会触发安全熔断。熔断状态存放在 `/app/data/provider-circuit.json`，文件损坏时 fail-closed。管理员可通过 Fly Secret `PAID_API_EMERGENCY_STOP=true` 立即手动封锁所有付费接口。

## 剩余边界

- `PILOT_ACCESS_CODE` 是共享口令，不是用户账号系统。参与者转发口令后仍可共享额度，但无法突破全局每日预算。
- 每客户端 24 小时额度保存在单实例内存中，Machine 重启会重置；持久化全局每日预算不会重置，并继续限制总费用。
- 分布式攻击者可以轮换 IP，但最多耗尽当天预算，不能继续产生无限上游调用。公开发布前若取消试点访问码，应改用账号、设备证明或边缘 WAF。
- Fly.io 部署优先使用 Fly Proxy 明确写入的 `Fly-Client-IP`；其他受控代理才使用 `X-Forwarded-For`。每日预算 JSON 无法解析时会 fail-closed，停止新的付费调用而不是清零计数。
- 实际账单以 Qwen、OpenAI 和 Fly.io 控制台为准；应用日志只记录 token、耗时、模型和错误，不记录截图或提示词。
- 应用熔断只能阻止经过 TabiTabi 服务的请求。如果 Fly Secrets、供应商账号或 API Key 本身泄露，攻击者可能绕过应用直接调用；供应商侧 API 限制、每日配额、账单告警和立即轮换凭证仍是最终止损边界。
